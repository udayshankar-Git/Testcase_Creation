# Navigation steps for Ezdocs liability
Login to ezdocs application
Select EzDocs liability LOB
click on search submission and provide the submission number
click on Get Submission
validate all the details fetched from uwd in submission details screen and click on next
select the product as excess in information screen
Provide all mandatory details in information screen and navigate to coverages screen
validate occurance limit, other aggregate limit, products-completed operations aggregate field types displaying as text field which accepts currency along with limits
validate limit of liability text field under other limit section also accepts currency along with limts
create quote binder policy and generate documents
validate the currency and limits are populated correctly in generated documents
# Navigation steps for Received liability
Login to ezdocs application
Select Received liability LOB 
click on search submission and provide random contract id
click on get submission
Provide all mandatory fields on create submission section and click on next
select the product as excess in information screen and provide all mandatory details
Navigate to coverages screen
validate occurance limit, other aggregate limit, products-completed operations aggregate field types displaying as text field which accepts currency along with limits
validate limit of liability text field under other limit section also accepts currency along with limts
validate the currency and limits are populated correctly in generated documents
